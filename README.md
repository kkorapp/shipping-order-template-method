# Shipping Order Template Method

Java console application demonstrating Template Method pattern.

## Features
- Abstract class (ShipmentOrder)
- Interface (SummaryPrintable)
- Template Method (processOrder)
- Polymorphism
- Different shipment types

## Classes
- ShipmentOrder
- DomesticCourierShipment
- PickupPointShipment
- InternationalShipment
- Main

Run Main.java to test.
